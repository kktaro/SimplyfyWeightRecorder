# Triage ラベル

スキルは5つの標準 triage ロールで話す。このファイルは、それらのロールとこのリポジトリの issue tracker で実際に使うラベル文字列の対応を定める。

| mattpocock/skills でのラベル | このリポジトリでのラベル | 意味                                       |
| ---------------------------- | ------------------------ | ------------------------------------------ |
| `needs-triage`               | `needs-triage`           | メンテナによる評価が必要                   |
| `needs-info`                 | `needs-info`             | 報告者からの追加情報待ち                   |
| `ready-for-agent`            | `ready-for-agent`        | 仕様が確定しており、AFK エージェントが着手可能 |
| `ready-for-human`            | `ready-for-human`        | 人間による実装が必要                       |
| `wontfix`                    | `wontfix`                | 対応しない                                 |

スキルがロールに言及したとき（例:「AFK-ready の triage ラベルを付ける」）は、この表の対応するラベル文字列を使う。

実際に使う語彙に合わせて「このリポジトリでのラベル」列を編集してよい。
